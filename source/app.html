Retro game console · offline

NES, Game Boy / Color / Advance, SNES, Genesis, Master System, Game Gear, N64, PlayStation, Atari 2600, TurboGrafx-16, Lynx, 32X, Sega CD, Saturn, Nintendo DS, Virtual Boy, Neo Geo Pocket, WonderSwan, Atari 7800 / 5200 / Jaguar, ColecoVision and arcade (FBNeo / MAME 2003-Plus). Zipped games work too. Games stay on this device.

Install: in Chrome, tap ⋮ → Add to Home screen (or Install app). It then opens full-screen and works with no connection.
Controllers: clip in a Backbone One, or pair an Xbox, PlayStation, Switch Pro or 8BitDo pad over Bluetooth (or plug in USB). Press any button once after opening the app so the browser picks it up. The first controller is Player 1 and a second one is Player 2. Remap buttons from the in-game menu.
Saves: in-game saves are kept automatically. NES has 3 quick-save slots in its menu; other systems have save/load state in their bottom bar.
Disc games (PlayStation, Sega CD, Saturn): use .chd files, or a .zip holding the .cue + .bin files.
\n BIOS files: Sega CD, Saturn, Atari 5200 and ColecoVision need the console's BIOS. Add it like a game; it's kept once and used automatically.
\n Arcade: add game zips with their original short names (sf2.zip, mslug.zip). Neo Geo games also need neogeo.zip added once. Use non-merged sets.
Only play ROMs you have the right to use — homebrew games or dumps of cartridges you own.
Non-NES systems use EmulatorJS and RetroArch cores (GPL-3.0).
